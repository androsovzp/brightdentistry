## 🌟 Основні можливості

- **🛍️ Зручний каталог товарів**:
  - Категоризація (Зубні пасти, Щітки, Мінералізація, Міжзубний догляд, Дитячий догляд тощо).
  - Миттєвий живий пошук за назвою або описом товару.
  - Фільтрація за брендами, ціновим діапазоном, наявністю.
  - Сортування за ціною (від дешевих/дорогих) та за популярністю.

- **🛒 Функціональний кошик & Оформлення замовлення**:
  - Інтерактивна висувна панель кошика (`CartDrawer`) із підрахунком підсумкової вартості.
  - Форма оформлення замовлення (`checkout`) із вибором способу доставки (Нова Пошта, Укрпошта, Самовивіз) та оплати.

- **📱 Інтеграція з Telegram Bot API**:
  - Автоматична передача нових замовлень безпосередньо в Telegram-канал або чат адміністратора клініки в режимі реального часу.

- **💎 Преміальний UI/UX дизайн**:
  - Адаптивна верстка під мобільні пристрої, планшети та ПК.
  - Оформлення на Tailwind CSS у стильних світлих та рожево-блакитних тонах.
  - Швидка модальна картка для детального перегляду товару (`ProductModal`).
  - Система інтерактивних сповіщень (`Toast`).

- **⚡ Максимальна продуктивність**:
  - Побудовано на **Next.js 14** (Static Site Generation / SSG) для розрядки сервера та миттєвого відкриття сторінок.

## 🛠️ Стек технологій

- **Frontend Framework**: [Next.js 14](https://nextjs.org/) (Pages Router)
- **UI Бібліотека**: [React 18](https://react.dev/)
- **Стилізація**: [Tailwind CSS 3](https://tailwindcss.com/)
- **Іконки**: [Lucide React](https://lucide.dev/)
- **Управління станом**: Custom React Context Store (`lib/store.js`)
- **Бекенд / API**: Next.js API Routes (`pages/api/order.js`)
- **Сповіщення**: Telegram Bot API (`lib/telegram.js`)
- **Хостинг**: [Vercel](https://vercel.com/) (`vercel.json`)

## 🚀 Швидкий запуск розробки

### 1. Клонування репозиторію
```bash
git clone https://github.com/androsovzp/brightdentistry.git
cd brightdentistry
```

### 2. Встановлення залежностей
```bash
npm install
```

### 3. Налаштування змінних оточення
Створіть файл `.env.local` у корені проекту за зразком `.env.example`:

```env
TELEGRAM_BOT_TOKEN=your_telegram_bot_token
TELEGRAM_CHAT_ID=your_telegram_chat_id
NEXT_PUBLIC_SITE_URL=http://localhost:3000
```

### 4. Запуск у режимі розробника
```bash
npm run dev
```
Відкрийте [http://localhost:3000](http://localhost:3000) у вашому браузері.

### 5. Збірка для продакшну
```bash
npm run build
npm run start
```

## ☁️ Деплойment (Vercel)

Проект повністю оптимізовано для публікації на [Vercel](https://vercel.com/):

1. Підключіть ваш GitHub репозиторій `androsovzp/brightdentistry` у панелі Vercel.
2. Вкажіть змінні оточення `TELEGRAM_BOT_TOKEN` та `TELEGRAM_CHAT_ID` у налаштуваннях проекту (Environment Variables).
3. Натисніть **Deploy**.
